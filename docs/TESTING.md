# 水果营养性价比 Skill：分阶段验收报告

验收日期：2026-10-16（分析系统日期）；环境 Python 3.13.5 / SciPy / pytest；测试执行于本地隔离环境。

## 版本1：V1.0（首次验收）

- 实现：8种水果，来源与条目识别，别名，营养档案，用户价格单位换算，模拟价格隔离，过期报价与跨地区报价拒绝，营养排名，替代推荐，FDC API读取/导入适配器（HTTP模拟测试）。
- 初次执行测试发现的错误：同一水果别名和ID重复时的自冲突。已修复为“同一水果别名允许，跨水果别名冲突拒绝”。
- 修复后的测试结果：**26 passed, 0 failed**。
- 日志：`reports/v1.0-test-results.txt`。

## 版本2：V1.1（完整升级）

- 新功能：每元多营养帕累托前沿、临界价格、最小成本水果组合、固定预算最大化最低营养目标完成率、每日食用量与能量上限、整数包装、散称商品、采购/食用日分离、保质期、最低品种、每次采购日固定费用、不同预算采样非劣组合、可食率与额外损耗自定义覆盖、SHA256审计记录、Markdown报告。
- 实测七日示例：8候选、7天、每天200–350g、指定三项演示营养目标、至少3种水果、模拟价格环境；解算器报告最优，采购方案产生且每个营养约束满足。
- 独立验证：针对仅散称和仅整盒商品进行穷举/解析值对照；用多个天数和最低品种数测试结果及成本单调性；测试不可行约束必须拒绝。
- 首轮升级测试：65 passed；集成测试增加之后曾出现1项测试断言错误（pytest.approx不支持嵌套字典），已修复测试方式，业务代码未受影响。
- 最终结果：**79 passed, 0 failed**。
- 日志：`reports/v1.1-final-test-results.txt`。

## 明确未通过真实世界端到端验证的部分

1. **在线FDC API**：该环境无法连接 `api.nal.usda.gov`，已经使用模拟HTTP响应校验接口解析与安全拒绝逻辑，但尚未在可联网环境完成真实请求测试。
2. **照片识别**：Skill 在支持视觉的 ChatGPT 宿主中由多模态模型识别水果；CLI 不提供本地视觉模型，不能说纯Python已经通过真实图片识别准确率测试。
3. **实时零售价**：没有可靠的当前地区实际水果零售价格数据输入，因此只提供严格标记的模拟价格测试；未证实当前任何城市的水果绝对性价比冠军。
4. **可食率/货架期**：内置为公开标记的规划假设，不是按水果批次独立测量，因此数值最优是对假设成立的条件性数学最优。
5. **不限规模的优化模型**：测试覆盖8种水果、最多31天输入的建模合法性和常见7天问题；大规模自定义目录求解可能受MILP时限影响，如果未能证明最优，程序会停止并明确报错。

## 审查结论

V1.0 与 V1.1 的已实现离线核心计算链通过自动测试，不存在已知未处理的测试失败。对照片、真实价格、实际品种与在线API的完全可靠性**不能保证**；这些依赖真实输入和联网部署。最终结论严格限制于可验证数据与给定约束。
